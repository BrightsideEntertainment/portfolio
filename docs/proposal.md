# Proposal IM5 – Portfolio Thomas Häder

**Projekttitel:** Portfolio Thomas Häder

**Fragestellung:**
Wie präsentiere ich ein breites, medienübergreifendes Portfolio (Film, Audio, Branding, Podcast, Moderation) so, dass Besuchende schnell das Passende finden und ich die Inhalte selbst unkompliziert pflegen kann?

**Geplante Methoden / Technologien:**
- HTML, CSS, JavaScript (Filter und Inhalte per fetch, ohne Neuladen)
- PHP 8 mit MySQL-Datenbank auf Hostpoint
- Eigener Admin-Bereich mit Login (CRUD für Projekte, Bild-Upload)
- oEmbed-API für YouTube, Vimeo und Spotify
- Automatischer Deploy via GitHub Actions

**Erwartete Ergebnisse:**
Eine live erreichbare, responsive Portfolio-Website mit dynamisch geladenen Projekten, Kategorie-Filter, Detailseiten mit eingebetteten Medien, Kontaktformular und geschütztem Verwaltungsbereich. Dazu ein öffentliches GitHub-Repository mit Dokumentation.
